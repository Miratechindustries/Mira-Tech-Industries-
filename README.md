# MiraTech Industries - Parallax Website

A modern, aesthetic corporate website featuring parallax effects, glassmorphism design, and transparent logo integration.

## Features

- **Modern Aesthetic Design** - Clean typography with Space Grotesk and Inter fonts
- **Parallax Effects** - Smooth scrolling parallax on background elements
- **Glassmorphism** - Frosted glass effect with backdrop blur
- **Animated Gradients** - Interactive mesh gradients responding to mouse movement
- **Responsive Design** - Optimized for all screen sizes
- **Interactive Elements** - Smooth hover effects and transitions
- **Contact Form** - Functional inquiry form
- **AI Chat Widget** - Interactive assistant panel

## Tech Stack

- HTML5
- CSS3 (Modern features: Grid, Flexbox, CSS Variables, Animations)
- Vanilla JavaScript
- Google Fonts (Space Grotesk, Inter)

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/miratech-parallax.git
   cd miratech-parallax
   ```

2. **Open in browser:**
   - Simply open `index.html` in your preferred browser
   - Or use a local server: `python -m http.server 8000`
